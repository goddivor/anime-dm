Instructions d'installation

  1. Lancez AnimeDownloadManager-{{version}}-setup.exe, depuis le dossier Téléchargements de votre navigateur.
  2. Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur Informations complémentaires puis sur Exécuter quand même. L'installateur n'est pas encore signé par un certificat payant ; SmartScreen le signale tant qu'il n'est pas assez répandu.
  3. Acceptez la demande d'autorisation. L'installateur a besoin des droits d'administrateur une seule fois, pour poser l'application dans Program Files\Anime Download Manager.
  4. Suivez l'assistant, puis laissez cochée la case « Exécuter Anime Download Manager » sur la dernière page.
  5. Installez une source. Au premier lancement, ouvrez l'Addon Store (bouton Addons de la barre d'outils) et installez la source du site que vous utilisez : Voir-Anime, French-Stream ou Wiflix.
  6. Ajoutez votre premier animé avec le bouton Ajout URL (Ctrl + N), en collant l'adresse de sa page.

ADM n'écrit jamais dans son dossier d'installation : votre liste, vos réglages et vos sources vivent dans %APPDATA%\anime-dm. Une nouvelle version s'installe par-dessus l'ancienne et garde tout.

Mises à jour

Vous n'avez pas besoin de revenir ici : quelques secondes après le démarrage, ADM vérifie s'il existe une version plus récente, vous la propose avec ses notes, puis la télécharge et l'installe si vous acceptez. Vous pouvez aussi la chercher à tout moment par Aide › Mise à jour rapide.

Désinstallation

Passez par Paramètres › Applications de Windows. La désinstallation ferme ADM, retire son démarrage automatique et sa déclaration aux navigateurs, puis vide %APPDATA%\anime-dm en gardant les sources installées, sauf si vous cochez la case qui les retire aussi. Les vidéos téléchargées ne sont jamais touchées.
