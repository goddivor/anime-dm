ADM contains the logic of no site. Each site is served by a source: a small library that knows how to read its pages, list the episodes of an anime, and find the players of an episode. You install, update, or remove it from the Addon Store, the Addons button of the toolbar.

Installing a source

  1. Click Addons in the toolbar.
  2. Select the source in the list, then click the download button at the top right.
  3. The source is ready: paste the address of an anime from its site into Add URL, and ADM picks it automatically.

When a site changes its address

Some sites change their domain name regularly. No need to wait for a new version: select the source in the Addon Store, click the gear, and enter the new address in the URL du site (site URL) field.

Why you can trust them

  • The address of the store is built into the application: it is not a list anyone could change.
  • Each source carries a SHA-256 checksum in the store index; ADM checks it before it even writes the file to the disk.
  • A source opens no connection by itself: every request goes through the application.
  • Their code is public, in the anime-dm-addons repository.

Suggesting a source

A source is written in Rust and compiled into a Windows library. The anime-dm-addons repository describes the interface and contains the three existing sources, to use as models. Open a pull request: once reviewed, the source joins the store.

ADM neither hosts nor provides any content: it downloads what the sites serve. It is up to you to check that you have the right to download what you download. Read the disclaimer.
