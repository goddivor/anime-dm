Download acceleration

Anime Download Manager pulls each video through eight connections at once and runs three episodes side by side; both numbers can be changed in the Options (up to 16 connections and 10 simultaneous downloads). When a host offers both a direct file and an HLS playlist, ADM takes the direct file: byte ranges are what make it faster.

Download from your favorite sites

With the ADM extension, keep browsing as usual. Hover the poster of an anime or the link of an episode: a "Download with ADM" panel settles on it. On the page of an anime or an episode itself, the button waits in the corner.

{{browser browser-hover-poster "voir-anime.to" "The Download with ADM panel settled on the hovered poster of an anime site's home page"}}

All the common browsers

ADM registers with Google Chrome, Microsoft Edge, Brave, Chromium, Vivaldi, Opera, and Mozilla Firefox; you choose which ones in Options › General. The extension never talks to the network: it hands the address to the application, which does all the work.

Add in three windows, as in IDM

The address, then the information (folder, folder icon, poster, number of episodes), then the choice of episodes. The source picks itself from the address, and the link on the clipboard is pasted when the window opens. Each add lives in its own windows: open as many as you like, the main window stays free.

Batch download

Copy a list of anime or episode addresses from anywhere, then press Ctrl + Shift + V. ADM groups them by anime and opens an add window for each, with the source chosen and the episodes checked; a notice counts the addresses no source serves.

Dark theme

The dark theme of ADM covers the main window, the menus, the dialogs, and the toolbar; its colors match those of IDM 6.43 to the pixel. It can also follow the Windows setting. The light theme is one click away, in View › Mode.

{{img theme-split "The same window in the dark theme and the light theme"}}

Dynamic segmentation

When a download starts, nobody knows how many connections the host will accept. So ADM does not split the file in advance: it starts from a single segment, and each connection that frees up takes half of the largest remaining segment (never less than one megabyte). Every connection stays busy until the end, then the parts are joined in order.

Download resume

Positions are saved every three seconds. After a stop, a cut, or a restart, ADM reads the page again, gets a new address for the video (host addresses expire), and resumes where it stopped, provided the size has not changed. A player no longer answers? Resume the episode with another one, from the context menu.

{{img menu-resume "Context menu of a failed episode: Resume, then Automatic or one of the source's players"}}

Scheduler

Two queues, the main one and the scheduler's. Start a queue once on a given date or every day on the checked days, stop it at a set time, and choose what happens once it is done: nothing, quit ADM, or shut down the computer.

Followed animes

Enter the release day and time of an anime that is still airing. On the first check, ADM offers the episodes already released that your list is missing; after that, it adds each new episode to the anime's folder on its own, and starts it if you wish.

{{img follow "Follow an anime window: release day, time, target queue, and immediate start"}}

Folder icons and Aniyomi

ADM dresses the folder of each anime with an icon made from its poster, in the template of your choice (dark or light DVD box, Blu-ray case, disc, vertical folder, and more). The icon is named by its file name alone, so the folder keeps it when it is renamed, moved, or copied to another disk. The Aniyomi option adds cover.jpg and .nomedia for a library on your phone.

{{img folder-icons "Folders dressed by ADM in Windows File Explorer"}}

The Categories panel

Each anime appears there with its poster, its title, and its number of episodes; a chevron folds or unfolds it, and ADM remembers. Click an anime to filter the list, or right-click it to open its folder, change its icon, move it to a queue, or follow it.

{{img main-light "The Categories panel in the light theme, with the posters of the animes"}}

Export and import

Tasks › Export writes the selection, or the whole list, to the ADM file (.adm, complete), a text file of addresses, JSON, CSV, or an Excel (.xlsx) or OpenDocument (.ods) workbook. Tasks › Import reads all of these back, finds the source of each address, and skips the episodes already in the list.

{{img menu-list "Context menu of the list: open, open folder, resume, stop, move to the queue, delete"}}

A store of verified sources

Sites are not hard-coded in the application: each one is a source that the Addon Store installs, updates, or removes. The address of the store is built into the application, and each source carries a SHA-256 checksum, verified before anything is written to the disk. The settings of a source, such as the address of its site, are changed from the store.

Quietly next to the clock

The close button of the window tucks ADM into the notification area: downloads, scheduler, followed animes, and the extension keep running. A notification announces each finished episode, the tooltip counts the running transfers, and ADM starts with Windows, its window hidden.

{{img options-general "Options, General tab: start with Windows, notification area, clipboard, and integrated browsers"}}

Built-in updates

A few seconds after it starts, ADM quietly checks whether a newer version exists. If one does, it offers it with its release notes; once you accept, it downloads, installs, and reopens the application. Help › Quick update looks for it on demand.
