Installation and updates

Which systems does ADM run on?

Windows 10 and Windows 11, 64-bit. The application ships as a single executable, with no library to install alongside it.

Windows says "Windows protected your PC." Is that normal?

Yes. The installer is not yet signed with a paid certificate, and SmartScreen flags any program that is not widely used yet. Click More info, then Run anyway. The code of ADM is public on GitHub.

Where does ADM keep my list and my settings?

In %APPDATA%\anime-dm: the list (downloads.json), the settings, the followed animes, the posters, and the installed sources. ADM never writes to its installation folder.

How do I update ADM?

You have nothing to do: ADM checks for a new version on its own after each start and offers it to you. To look for it right away: Help › Quick update. The update keeps your list and your settings.

ADM starts with Windows. How do I stop that?

Uncheck Start Anime Download Manager when Windows starts in Options › General.

Does uninstalling delete my videos?

No, never. It empties %APPDATA%\anime-dm while keeping the installed sources, unless you check the box that removes them too.

Browser integration

Which browsers are supported?

Google Chrome, Microsoft Edge, Brave, Chromium, Vivaldi, Opera, and Mozilla Firefox. You choose which ones ADM registers with in Options › General.

Where do I get the extension?

The Install the extension… button in Options › General opens its page. Its publication on the Chrome Web Store and the Firefox add-ons site is in progress; see the Browser integration page for its status.

The "Download with ADM" button does not show up on a site.
  1. Check that a source serves the site: it must be installed in the Addon Store.
  2. Check that your browser is checked in Options › General.
  3. Start ADM at least once after installing a source: it is what tells the extension which sites are served.
  4. Close and reopen the browser.
The panel shows up too often. Can I tone it down?

Yes: Options › General › Edit… chooses full or mini mode, and whether it appears on the pages, when hovering links, or both.

Does the extension send my data anywhere?

No. It never talks to the network: it only hands the address of the page to the application installed on your computer, when you click its button.

Sources and Addon Store

What is a source?

A small library that knows how to read a site: find the anime, its episodes, and their players. ADM contains none; you install the ones you need from the Addon Store. See the Sources page.

ADM says no source serves my address.

Install the source of the site from the Addon Store. If it is already installed, the site may have changed its address: set the new one in the Addon Store (gear button, URL du site field).

A site has changed its domain name.

Select its source in the Addon Store, click the gear, and enter the new address in URL du site (site URL). No need to wait for an update.

Can I add a site that is not supported?

Suggest it from the Contact page, or write its source yourself: the anime-dm-addons repository holds three to use as models.

Downloads and players

Where do my videos go?

To the folder shown in the Download information window, each anime in its own subfolder. Check Remember this path to have that folder offered for the next downloads; you can also change it in Options › Save to.

An episode failed. What do I do?

The chosen player no longer answers or does not have the video. Right-click the episode, then Resume, and pick another player in the list. Automatic lets the source try its players in its own order.

A finished episode is cut short or of poor quality.

A player sometimes serves an incomplete copy. Right-click, Resume, then another player: for a finished episode, ADM starts over from scratch with that player.

What is the difference between Stop and Delete?

Stop keeps what has already been received: Resume picks up from there. Delete removes the episode from the list and discards the received parts; the box in the confirmation also deletes the file from the disk.

How do I speed up or slow down downloads?

Options › Downloads sets the number of simultaneous downloads (1 to 10) and of connections per download (1 to 16). Some hosts limit the number of connections: beyond that limit, more connections bring nothing.

Why are some files .ts?

Some players serve the video as an HLS playlist, cut into small pieces. ADM joins them into a .ts file (or .mp4 for fragmented MP4), which VLC, mpv, and most players read.

Does the download resume after a cut?

Yes. Positions are saved every three seconds; on resume, ADM reads the page again to get a fresh address for the video, and continues where it stopped if the file size has not changed.

Scheduler and followed animes

How do I download overnight?

Put the episodes in the scheduler queue (right-click, Move to the queue), then in Schedule › Queues, check Start this queue on its own, set the time, and optionally Shut down the computer once the queue is done.

How do I get the new episodes of an airing anime?

Right-click the anime in the Categories panel, Follow the new episodes…, then enter its release day and time. See Followed animes.

Why do I have to enter the release day?

Sites do not give the date of each episode. ADM fills in the day and time with the moment you follow the anime; correct them from the broadcast schedule.

General questions

Is ADM really free?

Yes: no trial period, no paid edition, no ads, and no account. Its code is public on GitHub.

Does ADM provide videos?

No. ADM neither hosts nor provides any content: it downloads what the sites serve. It is up to you to check your right to do so; read the disclaimer.

The close button does not quit ADM.

It tucks it into the notification area, next to the clock, so that downloads keep running. To quit: Tasks › Quit, or right-click the ADM icon next to the clock, then Quit. This behavior is set in Options › General.

Can I use ADM in French?

Yes: View › Language › Français.

Do my IDM toolbar skins work?

Yes. Drop them into %APPDATA%\anime-dm\toolbar and pick them with View › Toolbar. See Toolbar.
