Main window

The main window shows the list of episodes: file name, size, status, time left, speed, last try, date added, location, address, and parent page. Click a column header to sort the list; during a transfer, the status cell turns into a progress bar.

Above the list, the Add URL, Resume, Stop, Stop all, Delete, Delete all, Options, Schedule, Addons, and Find buttons turn on or gray out depending on what the selection allows. Menu entries follow the same rule.

Resume restarts stopped or failed episodes where they left off. Stop keeps what has been received; Delete removes the episode from the list and, if you check the box in the confirmation, its file from the disk.

Categories panel

The left panel groups episodes by anime, under its poster, with their count. A chevron folds or unfolds an anime, and ADM remembers. Below come the two queues: the main queue and the scheduler queue.

Click a row to filter the list. Right-click an anime to open it in your browser, open its folder, change the folder icon, prepare the series for Aniyomi, move it to a queue, follow it, or delete it. The panel is hidden with View › Categories, and its width is set by dragging the splitter.

Adding a download

Click Add URL (Ctrl + N). Adding takes three windows, as in IDM.

1. The address

Paste the address of an anime or episode page; if it is already on the clipboard, it fills in by itself. The source that serves this site is picked automatically. Click OK: ADM reads the page, and the next window arrives once the episodes are known.

2. The information

Check the save folder: each anime gets its own subfolder there. Remember this path offers it for the next downloads. Choose the folder icon template, then click the episodes button to pick them. Start launches the download; Later drops the episodes, stopped, into the main queue.

3. The episodes

Check the episodes in the grid, or type a selection such as 1-8 or 1-5,12: the grid and the field answer each other. The player chosen at the top applies to all; right-click an episode to give it its own.

Each add lives in its own windows, with a button on the taskbar. You can open several at once and keep using the main window in the meantime.

Batch download

Copy several addresses (anime or episode pages, one per line or mixed with text), then choose Tasks › Batch download from clipboard (Ctrl + Shift + V). ADM groups them by anime and opens an add window for each, with the source chosen and the named episodes checked (all of them, for an anime page). A notice counts the addresses no installed source serves.

Context menu

Right-click episodes in the list for Open (a finished file), Open folder, Resume, Stop (a running transfer), Move to the queue, and Delete.

Resume is a submenu: Automatic lets the source try its players in order, the other entries force a player. The current player is checked. For a stopped or failed episode, ADM resumes where it left off; for a finished episode, it starts over from scratch, because a player sometimes serves a cut copy where another has the whole video.

Options window

The Options button opens the configuration of ADM, in three tabs. OK applies, Cancel changes nothing.

General

Starting with Windows, closing to the notification area, pasting the clipboard when the add window opens, the browsers ADM registers with, the Install the extension… button, and the setup of the browsers' download panel (Edit…).

Save to

The download folder and the box that offers it for every new download, the icon applied to each anime's folder with its template, and the automatic preparation for Aniyomi (cover.jpg and .nomedia).

Downloads

The number of simultaneous downloads (1 to 10), which applies at once, and the number of connections per download (1 to 16), which applies to the next transfers.

Columns, font, theme

View › Customise columns chooses the columns shown and their order; the file name stays first. Drag a separator in the header to set a width: ADM keeps it. View › Font changes the font of the toolbar, the panel, and the list, View › Mode chooses the dark, light, or Windows theme, and View › Toolbar the look of the buttons (see Toolbar).

Export and import

Tasks › Export writes the selection, or the whole list if nothing is selected, in one of these formats:

  • ADM file (.adm): everything, animes, posters, sources, episodes, players, and queues;
  • Text: one page address per line;
  • JSON: a flat list;
  • CSV, Excel (.xlsx), or OpenDocument (.ods): a table, one row per episode.

Tasks › Import reads any of these back. For a bare address, ADM finds the source from the site and queries the page: every episode for an anime page, that one alone for an episode page. Episodes already in the list are skipped, the others wait, stopped, in the main queue.

Notification area

The close button of the window tucks ADM next to the clock without stopping it. Click its icon to reopen the window; right-click it for adding, batch download, the queues, the scheduler, the options, the Addon Store, and Quit. The tooltip counts the running transfers, and a notification announces each finished episode when the window is not in the foreground. To make the close button really quit, uncheck the option in Options › General.

About and updates

Help › About Anime Download Manager gives the version and the build date, and the Check for updates button. ADM also runs that check on its own, quietly, after each start: it says nothing if there is nothing new.
