Principles

  • The file is split during the download, by halving the largest remaining segment, not in advance.
  • A connection that finishes its segment takes another one right away, with no needless new negotiation.
  • The number of connections and of simultaneous downloads can be tuned to your line and to the host.
  • No ffmpeg: everything goes through plain HTTP requests.

The four stages

{{partial segments}}
  1. Probe. A first request that asks for a single byte (Range: bytes=0-0) gives the size of the video and tells whether the host accepts being asked for it in pieces.
  2. Dynamic segmentation. At the start, nobody knows how many connections the host will accept, so the file starts as a single segment. Each connection that frees up finds the largest remaining segment, splits it in half, and downloads the second half. A segment is never split below one megabyte. As a result, every connection stays busy until the end, and a slow connection gets help from the fast ones.
  3. Saved positions. Each segment writes its own part in %APPDATA%\anime-dm\parts, and positions are saved every three seconds.
  4. Joining. Once every segment has arrived, the parts are put end to end, in order, into the final file; the parts folder is then deleted.

Stop and resume

Thanks to the saved positions, a stop, closing ADM, a network cut, or a power failure only loses a few seconds. Video addresses expire: on each resume, ADM reads the episode page again and gets a fresh address. The resume is only accepted if the file size has not changed; otherwise, the episode starts over from scratch so as not to mix two copies.

HLS playlists

Some players serve the video as an .m3u8 playlist, cut into hundreds of small pieces. ADM treats these pieces as segments: several connections pull them in parallel, AES-128 encryption is undone on the way, and the final file gets the .ts extension, or .mp4 for fragmented MP4. When a host offers both a direct file and a playlist, ADM chooses the direct file: it is the one that benefits most from segmentation.

Settings

In Options › Downloads: the number of simultaneous downloads (3 by default, from 1 to 10) and of connections per download (8 by default, from 1 to 16). On a slow line, fewer simultaneous downloads finish each episode sooner. Some hosts limit the number of connections per IP address: beyond their limit, adding more brings nothing.
