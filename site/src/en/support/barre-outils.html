Customizing the toolbar

The look of the ADM toolbar changes with View › Toolbar. The packs shipped with the application are animated: each button plays its animation when the pointer hovers it, and grays out when it has nothing to do. Hover the buttons below to see them as in the application.

Internet Download Manager skins

ADM accepts IDM toolbar skins: a .tbi file with its .bmp image strips.

  1. Download the skin you like and extract its archive.
  2. Copy its files into %APPDATA%\anime-dm\toolbar (type this address in the File Explorer address bar).
  3. Quit ADM with Tasks › Quit, then start it again: the skin appears in View › Toolbar.

IDM skins have no Addons or Find buttons: ADM lends them those of the Classique Rem pack.

Creating an animated pack

A pack is a folder of resources\toolbar holding a pack.json file (its name) and, for each button, a strip of images in a row with its JSON file (the size and duration of each image). The button names are add, resume, stop, stop-all, remove, remove-all, options, schedule, addons, and search. A PNG strip keeps its transparency, and so a halo; a BMP strip uses a transparent background color. The Classique Rem and Néon packs, in the repository, serve as models.
