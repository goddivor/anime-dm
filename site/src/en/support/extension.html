Download an anime without leaving its site

The ADM extension recognizes the anime and episode pages of the sites your sources serve. It places a button on them, and the same panel when you hover any link that leads there. One click hands the page to ADM, which opens the add window.

1. Prepare ADM and install the extension

  1. Install the site's source in the Addon Store: the extension only reacts on sites a source serves.
  2. Check your browser in Options › General, list Integrate with the following browsers. ADM registers with it at each start. Supported: Google Chrome, Microsoft Edge, Brave, Chromium, Vivaldi, Opera, and Mozilla Firefox.
  3. Install the extension from the Install the extension… button of the same tab, then close and reopen the browser.

The extension is being published on the Chrome Web Store and the Firefox add-ons site. Until that is done, the Install the extension… button cannot install it yet; this page will be updated as soon as it is available.

2. The button and the panel

On an anime page, the Download with ADM button waits in the bottom right corner (arrow 1). On an episode page, it becomes Download this episode with ADM.

Hover the link of an episode, in the list of an anime page: the panel settles to the right of its words, on its line (arrow 2). The pointer reaches it sideways without crossing the next link.

Hover the poster of an anime, on the home page or in a list: the panel settles on the poster (arrow 3).

3. ADM takes over

Click the button or the panel: ADM opens if it was not running, picks the site's source, reads the page right away, and opens the Download information window. From an episode, only that one is checked; all that is left is to click Start.

Each click opens its own add window, even if others are already open. Episodes coming from the browser join the main queue.

4. Set up the panel

Options › General › Edit… chooses the look of the panel: full, with its text, or mini, reduced to the logo. Two boxes decide where it appears: on the page of an anime or an episode itself, and over the links that lead there. The browser picks up the change in less than a minute.

5. The button does not show up

  1. Check that the site's source is installed, and that it knows the right address of the site (Addon Store, gear button, URL du site field).
  2. Check that your browser is checked in Options › General.
  3. Start ADM: it writes the list of served sites that the extension reads.
  4. Check that the extension is enabled on the browser's extensions page, then reload the site's page.
  5. Still nothing? Write to us with the browser and the address of the page.

Privacy

The extension never talks to the network. It exchanges with a small ADM program installed on your computer, which the browser starts alongside it, and only hands it an address when you click its button.
