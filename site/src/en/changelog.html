0.03 win-v0.03

October 27, 2026

Fixes

  • A failing connection no longer brings the download down: five failures in a row without a byte before it gives up, a growing pause from 1 to 16 s, and it steps back at the second refusal while other connections are served; its part goes to another connection, and the crew re-forms on its own. The same logic applies to HLS playlists. #110
  • The address of the video is read again from the source when a transfer fails on the network, keeping the parts already received. #110
  • The Categories panel is repainted whole when its client area changes size; the episode count no longer appears twice. #110

Additions

  • Options › Downloads: connections per server (24 by default) and retries per file (3 by default). #110
  • Engine test bench: download-smoke repaired and a test host, tools/hostile_host.py. #110

0.02 win-v0.02

October 4, 2026

Fixes

  • The icon of an anime's folder is named by its file name alone, so it follows the folder when it is renamed, moved, or copied. Folders dressed by 0.01 are repaired at startup. #99
  • The Categories panel saves an anime folded with the chevron. #100
  • Deleting an anime with its files also removes its folder once it holds nothing but its dressing. #101
  • The application starts with Windows by default; the option's label is clearer. #102

Pull requests: #103, #104, #105.

0.01 win-v0.01

September 25, 2026

The first version of the Windows application, rewritten in C++ (Win32) to replace the Tauri application.

Engine and sources

  • Download over parallel HTTP connections with dynamic segmentation, HLS playlists without ffmpeg. #45
  • Addon Store and sources as native libraries verified by SHA-256. #43, #67
  • Resume through any player of the source, including for a finished episode. #64, #65

Interface

  • An IDM-like window: colors measured on IDM 6.43, hand-painted rows, shell file type icons. #42, #49, #55, #57, #59
  • Categories panel with posters, chevrons, and Windows icons. #46, #92
  • Adding in three windows, then independent add windows and batch download. #61, #88
  • Sorting by column, extra columns, kept widths, choice of columns and font. #63, #75, #80, #82
  • Find in the list, row hover, Ctrl + A. #68, #76
  • Tabbed Options window and IDM-like About window. #69, #93
  • Menu entries grayed out when they have nothing to act on. #85
  • Notification area: close to tray, menu, notifications. #90
  • Window frame and panel kept from one session to the next. #89

Toolbar

  • Segoe Fluent Icons glyphs and IDM toolbar skins. #51
  • Animated Classique Rem (default) and Néon sprite packs. #52, #53, #79

Browser, scheduler, files

  • Browser extension and native messaging host. #69
  • Scheduler with two queues, then queues per anime. #71, #74
  • Followed animes, with an offer of the missing episodes. #72, #84
  • Folder icons made from the posters. #47
  • Export and import, then Excel and OpenDocument workbooks. #73, #86

Distribution

  • Installer, Windows releases, and built-in update; N.NN version numbers. #95

Removed

  • Manual download, speed limiter, and booster. #87, #91
