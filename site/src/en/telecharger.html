Installation instructions

  1. Run AnimeDownloadManager-{{version}}-setup.exe from your browser's Downloads folder.
  2. If Windows shows "Windows protected your PC," click More info, then Run anyway. The installer is not yet signed with a paid certificate, and SmartScreen flags it until it is widely used.
  3. Accept the permission prompt. The installer needs administrator rights once, to place the application in Program Files\Anime Download Manager.
  4. Follow the wizard, then leave the "Launch Anime Download Manager" box checked on the last page.
  5. Install a source. On first launch, open the Addon Store (the Addons button of the toolbar) and install the source of the site you use: Voir-Anime, French-Stream, or Wiflix.
  6. Add your first anime with the Add URL button (Ctrl + N), by pasting the address of its page.

ADM never writes to its installation folder: your list, your settings, and your sources live in %APPDATA%\anime-dm. A new version installs over the old one and keeps everything.

Updates

You do not need to come back here: a few seconds after it starts, ADM checks whether a newer version exists, offers it with its release notes, then downloads and installs it if you accept. You can also look for it at any time with Help › Quick update.

Uninstalling

Go through Windows Settings › Apps. Uninstalling closes ADM, removes its automatic start and its registration with the browsers, then empties %APPDATA%\anime-dm while keeping the installed sources, unless you check the box that removes them too. Downloaded videos are never touched.
