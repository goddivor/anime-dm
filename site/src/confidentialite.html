Politique de confidentialité

En bref : Anime Download Manager ne collecte rien. Il n'a ni compte, ni statistiques d'utilisation, ni publicité, ni pisteur.

Ce qui reste sur votre ordinateur

Votre liste de téléchargements, vos réglages, vos animés suivis, les affiches et les sources installées sont enregistrés dans %APPDATA%\anime-dm, sur votre ordinateur, et nulle part ailleurs.

Les seules connexions qu'ADM établit

  • Vers les sites que vous utilisez, et les hébergeurs de leurs lecteurs, pour lire les pages et télécharger les vidéos que vous avez demandées.
  • Vers GitHub, pour lire l'index de l'Addon Store, télécharger une source et vérifier s'il existe une nouvelle version de l'application.

Ces requêtes ne contiennent aucune information sur vous au-delà de ce que tout navigateur envoie (adresse IP, version du logiciel).

L'extension de navigateur

L'extension ne parle jamais au réseau. Elle lit l'adresse de la page affichée pour savoir si une source la sert, et ne transmet une adresse à l'application installée sur votre ordinateur que lorsque vous cliquez sur « Télécharger avec ADM ».

Ce site

Ce site est hébergé par GitHub Pages. Il n'utilise ni cookie, ni outil de mesure d'audience ; GitHub peut tenir des journaux techniques de connexion, selon sa propre politique de confidentialité.
