Les files

ADM a deux files : la file principale et la file du planificateur. Chaque épisode appartient à l'une d'elles ; le panneau Catégories les montre sous les animés. Démarrer la file reprend ses épisodes arrêtés ou en échec, Arrêter la file stoppe ceux qui tournent.

Mettre dans une file

Faites un clic droit sur des épisodes de la liste, ou sur un animé du panneau pour tous ses épisodes, puis Mettre dans la file : une coche montre la file actuelle. Le bouton Plus tard de la fenêtre d'ajout dépose les épisodes, arrêtés, dans la file principale.

Programmer une file

Cliquez sur Planifier, puis, dans l'onglet Files, choisissez la file et réglez :

  • le démarrage automatique : une fois, à une date et une heure, ou chaque jour, aux jours cochés ;
  • l'arrêt automatique, à une heure fixe ;
  • ce qui se passe une fois la file terminée : rien, quitter ADM ou éteindre l'ordinateur.

La liste du bas montre les fichiers de la file et leur état ; Démarrer maintenant la lance sans attendre. ADM doit être ouvert, même caché dans la zone de notification, pour que la file démarre à l'heure dite.

Une session interrompue (coupure de courant, redémarrage) ne laisse rien en attente : au lancement suivant, tout ce qui était actif passe à l'état arrêté, et c'est la file programmée ou vous qui le relancez.

Les animés suivis

Un animé suivi est vérifié régulièrement ; ses nouveaux épisodes sont ajoutés d'eux-mêmes dans son dossier, et lancés si vous le souhaitez. L'onglet Animés suivis les liste, avec le dernier épisode paru, le jour de sortie et la prochaine vérification ; Vérifier maintenant n'attend pas.

Suivre un animé

  1. Faites un clic droit sur l'animé dans le panneau Catégories, puis Suivre les nouveaux épisodes… (ou Suivre un animé… dans l'onglet).
  2. Indiquez le jour et l'heure de sortie. Les sites ne donnent pas la date des épisodes : ADM préremplit ces champs avec le moment présent, à vous de les corriger d'après le calendrier de diffusion.
  3. Choisissez la file qui recevra les nouveaux épisodes, et s'ils démarrent aussitôt.
  4. Validez. La première vérification vous propose les épisodes déjà sortis qui manquent à votre liste : ceux qui suivent votre dernier épisode téléchargé sont cochés, les plus anciens non.

Le rythme des vérifications

ADM vérifie la page de l'animé au moment de la sortie, puis toutes les trois heures pendant deux jours tant que l'épisode n'a pas paru. Dès qu'il paraît, ou après ces deux jours, la vérification suivante est programmée pour la semaine d'après.
