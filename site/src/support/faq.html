Installation et mises à jour

Sur quels systèmes ADM fonctionne-t-il ?

Sur Windows 10 et Windows 11, en 64 bits. L'application est livrée en un seul exécutable, sans bibliothèque à installer à côté.

Windows dit « Windows a protégé votre ordinateur ». Est-ce normal ?

Oui. L'installateur n'est pas encore signé par un certificat payant, et SmartScreen signale tout programme encore peu répandu. Cliquez sur Informations complémentaires, puis sur Exécuter quand même. Le code d'ADM est public sur GitHub.

Où ADM range-t-il ma liste et mes réglages ?

Dans %APPDATA%\anime-dm : la liste (downloads.json), les réglages, les animés suivis, les affiches et les sources installées. ADM n'écrit jamais dans son dossier d'installation.

Comment mettre ADM à jour ?

Vous n'avez rien à faire : ADM vérifie seul l'existence d'une nouvelle version après chaque démarrage et vous la propose. Pour la chercher tout de suite : Aide › Mise à jour rapide. La mise à jour garde votre liste et vos réglages.

ADM se lance au démarrage de Windows. Comment l'en empêcher ?

Décochez Lancer Anime Download Manager au démarrage de Windows dans Options › Général.

La désinstallation supprime-t-elle mes vidéos ?

Non, jamais. Elle vide %APPDATA%\anime-dm en gardant les sources installées, sauf si vous cochez la case qui les retire aussi.

Intégration au navigateur

Quels navigateurs sont pris en charge ?

Google Chrome, Microsoft Edge, Brave, Chromium, Vivaldi, Opera et Mozilla Firefox. Vous choisissez ceux auxquels ADM se déclare dans Options › Général.

Où trouver l'extension ?

Le bouton Installer l'extension… d'Options › Général ouvre sa page. Sa publication sur le Chrome Web Store et sur le site des modules de Firefox est en cours ; consultez la page Intégration au navigateur pour son état.

Le bouton « Télécharger avec ADM » n'apparaît pas sur un site.
  1. Vérifiez qu'une source sert ce site : elle doit être installée dans l'Addon Store.
  2. Vérifiez que votre navigateur est coché dans Options › Général.
  3. Lancez ADM au moins une fois après l'installation d'une source : c'est lui qui indique à l'extension les sites servis.
  4. Fermez puis rouvrez le navigateur.
Le panneau apparaît trop souvent. Peut-on le réduire ?

Oui : Options › Général › Éditer… choisit le mode complet ou mini, et s'il apparaît sur les pages, au survol des liens, ou les deux.

L'extension envoie-t-elle mes données quelque part ?

Non. Elle ne parle jamais au réseau : elle remet seulement l'adresse de la page à l'application installée sur votre ordinateur, quand vous cliquez sur son bouton.

Sources et Addon Store

Qu'est-ce qu'une source ?

Une petite bibliothèque qui sait lire un site : trouver l'animé, ses épisodes et leurs lecteurs. ADM n'en contient aucune ; vous installez celles dont vous avez besoin depuis l'Addon Store. Voir la page Sources.

ADM dit qu'aucune source ne sert mon adresse.

Installez la source du site depuis l'Addon Store. Si elle est déjà installée, le site a peut-être changé d'adresse : réglez la nouvelle dans l'Addon Store (roue dentée, champ URL du site).

Un site a changé de nom de domaine.

Sélectionnez sa source dans l'Addon Store, cliquez sur la roue dentée et indiquez la nouvelle adresse dans URL du site. Pas besoin d'attendre une mise à jour.

Puis-je ajouter un site qui n'est pas pris en charge ?

Proposez-le depuis la page Contact, ou écrivez sa source vous-même : le dépôt anime-dm-addons en contient trois à prendre pour modèle.

Téléchargements et lecteurs

Où vont mes vidéos ?

Dans le dossier indiqué dans la fenêtre Info sur le téléchargement, chaque animé dans son sous-dossier. Cochez Rappeler ce chemin pour que ce dossier soit proposé aux ajouts suivants ; il se change aussi dans Options › Enregistrer sous.

Un épisode est en échec. Que faire ?

Le lecteur choisi ne répond plus ou n'a pas la vidéo. Faites un clic droit sur l'épisode, puis Reprendre et choisissez un autre lecteur dans la liste. Automatique laisse la source essayer les lecteurs dans son ordre.

Un épisode terminé est tronqué ou de mauvaise qualité.

Un lecteur sert parfois une copie incomplète. Clic droit, Reprendre, puis un autre lecteur : pour un épisode terminé, ADM repart de zéro avec ce lecteur.

Quelle différence entre Arrêter et Supprimer ?

Arrêter garde ce qui a déjà été reçu : Reprendre repartira de là. Supprimer retire l'épisode de la liste et jette les parts reçues ; la case de la confirmation supprime aussi le fichier du disque.

Comment accélérer ou ralentir les téléchargements ?

Options › Téléchargements règle le nombre de téléchargements simultanés (1 à 10) et de connexions par téléchargement (1 à 16). Certains hébergeurs limitent le nombre de connexions : au-delà, plus de connexions n'apportent rien.

Pourquoi certains fichiers sont-ils en .ts ?

Certains lecteurs servent la vidéo en liste HLS, découpée en petits morceaux. ADM les assemble en un fichier .ts (ou .mp4 quand il s'agit de MP4 fragmenté), que lisent VLC, mpv et la plupart des lecteurs.

Le téléchargement reprend-il après une coupure ?

Oui. Les positions sont enregistrées toutes les trois secondes ; à la reprise, ADM relit la page pour obtenir une adresse fraîche de la vidéo, et reprend là où il en était si la taille du fichier n'a pas changé.

Planificateur et animés suivis

Comment télécharger la nuit ?

Mettez les épisodes dans la file du planificateur (clic droit, Mettre dans la file), puis, dans Planifier › Files, cochez Démarrer cette file automatiquement, l'heure, et éventuellement Éteindre l'ordinateur une fois la file terminée.

Comment recevoir les nouveaux épisodes d'un animé en cours ?

Clic droit sur l'animé dans le panneau Catégories, Suivre les nouveaux épisodes…, puis indiquez son jour et son heure de sortie. Voir Les animés suivis.

Pourquoi dois-je saisir le jour de sortie ?

Les sites ne donnent pas la date de chaque épisode. ADM préremplit le jour et l'heure avec le moment où vous suivez l'animé ; corrigez-les d'après le calendrier de diffusion.

Questions générales

ADM est-il vraiment gratuit ?

Oui : pas de période d'essai, pas de version payante, pas de publicité et pas de compte. Son code est public sur GitHub.

ADM fournit-il des vidéos ?

Non. ADM n'héberge ni ne fournit aucun contenu : il télécharge ce que les sites servent. Il vous revient de vérifier votre droit à le faire ; lire l'avertissement.

La croix ne ferme pas ADM.

Elle le range dans la zone de notification, à côté de l'horloge, pour que les téléchargements continuent. Pour quitter : Tâches › Quitter, ou clic droit sur l'icône d'ADM près de l'horloge, puis Quitter. Ce comportement se règle dans Options › Général.

Peut-on utiliser ADM en anglais ?

Oui : Affichage › Langue › English.

Mes peaux de barre d'outils d'IDM fonctionnent-elles ?

Oui. Déposez-les dans %APPDATA%\anime-dm\toolbar et choisissez-les par Affichage › Barre d'outils. Voir Barre d'outils.
