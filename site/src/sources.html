ADM ne contient la logique d'aucun site. Chaque site est servi par une source : une petite bibliothèque qui sait lire ses pages, lister les épisodes d'un animé et trouver les lecteurs d'un épisode. Vous l'installez, la mettez à jour ou la retirez depuis l'Addon Store, le bouton Addons de la barre d'outils.

Installer une source

  1. Cliquez sur Addons dans la barre d'outils.
  2. Choisissez la source dans la liste, puis cliquez sur le bouton de téléchargement en haut à droite.
  3. La source est prête : collez l'adresse d'un animé de son site dans Ajout URL, ADM la choisit d'office.

Quand un site change d'adresse

Certains sites changent régulièrement de nom de domaine. Inutile d'attendre une nouvelle version : sélectionnez la source dans l'Addon Store, cliquez sur la roue dentée et indiquez la nouvelle adresse dans le champ URL du site.

Pourquoi vous pouvez leur faire confiance

  • L'adresse du magasin est inscrite dans l'application : ce n'est pas une liste que n'importe qui pourrait modifier.
  • Chaque source porte une empreinte SHA-256 dans l'index du magasin ; ADM la vérifie avant même d'écrire le fichier sur le disque.
  • Une source n'ouvre aucune connexion elle-même : toutes les requêtes passent par l'application.
  • Leur code est public, dans le dépôt anime-dm-addons.

Proposer une source

Une source s'écrit en Rust et se compile en bibliothèque Windows. Le dépôt anime-dm-addons décrit l'interface et contient les trois sources existantes, à prendre pour modèle. Ouvrez une demande de fusion : une fois relue, la source rejoint le magasin.

ADM n'héberge ni ne fournit aucun contenu : il télécharge ce que les sites servent. Il vous revient de vérifier que vous avez le droit de télécharger ce que vous téléchargez. Lire l'avertissement.
